
# Free Web Development Resources

> A curated collection of free tools, software, websites, repositories, courses, services, and other resources that can help web developers build better things.

Whether you're a beginner learning your first technology or an experienced developer looking for a useful tool, this list aims to save you time and help you discover great resources.

**Everything listed here is free to use**, either completely free, open source, or available through a meaningful free tier.

## Development Tools

### Code Editors

- [Visual Studio Code](https://code.visualstudio.com/) - Free source-code editor with support for extensions, debugging, Git, and many programming languages.
    
- [Zed](https://zed.dev/) - Fast, modern code editor designed for collaborative development.
    

### Browser DevTools

- [Chrome DevTools](https://developer.chrome.com/docs/devtools/) - Built-in browser tools for debugging, profiling, and inspecting web applications.
    
- [Firefox Developer Tools](https://firefox-source-docs.mozilla.org/devtools-user/) - Browser developer tools for inspecting and debugging websites.
    

### API Development & Testing

- [Postman](https://www.postman.com/) - Platform for developing, testing, and documenting APIs with a free plan.
    
- [Insomnia](https://insomnia.rest/) - Open-source API client for designing and testing APIs.
    

### Database Tools

- [DBeaver](https://dbeaver.io/) - Free and open-source database management tool supporting many database systems.
    
- [DB Browser for SQLite](https://sqlitebrowser.org/) - Visual tool for creating, editing, and exploring SQLite databases.
    

### Git & GitHub

- [Git](https://git-scm.com/) - Distributed version control system for tracking changes in source code.
    
- [GitHub](https://github.com/) - Platform for hosting repositories, collaborating on code, and managing software projects.
    
- [GitHub CLI](https://cli.github.com/) - Command-line interface for working with GitHub.
    

### Terminal & CLI

- [Oh My Zsh](https://ohmyz.sh/) - Community-driven framework for managing Zsh configuration.
    
- [Starship](https://starship.rs/) - Fast and customizable cross-shell prompt.

## Contributing

This project is community-driven, and contributions are welcome!

If you know a useful free resource that is missing from this list, you can add it yourself by opening a Pull Request.

Please read [CONTRIBUTING.md](https://chatgpt.com/c/CONTRIBUTING.md) before contributing.

### Quick Contribution Rules

- Make sure the resource is relevant to web development.
    
- The resource must be free, open source, or have a useful free tier.
    
- Search the list before adding a new resource.
    
- Add the resource to the most appropriate category.
    
- Use the existing Markdown format.
    
- Keep descriptions short and objective.
    
- Do not submit affiliate links, referral links, or promotional content.
    
- Do not add duplicate resources.
    
- One resource per list item.
    
- Keep entries alphabetically sorted within a category whenever possible.
